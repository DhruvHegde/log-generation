# Syntax error scenarios for F1 dataset generation.
#
# Format: scenario_id|description|broken_app_py_content
#
# Each scenario is a COMPLETE, STANDALONE replacement for app.py.
# The content must be genuinely syntactically broken so that
# `python -c "import app"` raises SyntaxError, IndentationError, or TabError.
# Each scenario is independent — the generator writes it fresh to app.py
# before every commit, so no scenario depends on a previous one.
#
# Pipe characters (|) delimit fields; the content field uses \n for newlines
# and \t for tab characters.
#
# ORIGINAL 10 SCENARIOS (runs 1-100 used these cyclically)
